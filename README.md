# 〰️ LC 공진 주파수 계산기

**https://ajh-project.github.io/lc-resonance/**

f₀ = 1 / (2π√LC)

- L, C를 넣으면 공진 주파수 f₀ 계산
- 반대로 f₀와 L(또는 C)로 나머지 값도 계산
- 단위 선택(µH, nF, pF, MHz…) 또는 `4.7u`, `22pF`처럼 직접 입력
- 각주파수 ω₀, 주기 T, 특성 임피던스 Z₀ 함께 표시
- PC·모바일 브라우저, 라이트/다크 모드 지원

## 개발
```bash
npm install
npm run dev
npm run deploy   # GitHub Pages 배포
```
